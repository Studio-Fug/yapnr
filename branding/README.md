# yapnr brand assets

| File                                                 | Use                                                                            |
| ---------------------------------------------------- | ------------------------------------------------------------------------------ |
| `yapnr-logo.png`                                     | Full lockup (emblem + wordmark), 1254 px, transparent. For light backgrounds.  |
| `yapnr-logo-{512,256,128}.png`                       | Downscaled lockups (README, docs sidebar).                                     |
| `yapnr-logo-light.png`                               | Lockup recoloured for dark backgrounds.                                        |
| `yapnr-mark*.png`                                    | Emblem only (512, 180, 64, 32, 16 px); `-light` variants for dark backgrounds. |
| `favicon/yapnr-favicon.svg`                          | Simplified bold mark for 16-48 px; switches to light strokes in dark mode.     |
| `favicon/favicon.ico`, `favicon/yapnr-favicon-*.png` | Raster favicons (16/32/48, 180 for touch icons; `-dark` variants).             |
| `BACKSTORY.txt`                                      | The name and the mark: "yet another place and route" / Yavanna.                |
| `yapnr-logo-prompt.txt`                              | Provenance: the prompt used to generate the original logo.                     |

Palette: forest green `#024823`, antique gold `#ba9015`, light sage `#ddeee0` (green replacement on
dark backgrounds).
