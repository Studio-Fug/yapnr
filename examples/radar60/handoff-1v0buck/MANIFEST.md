# Reproduction manifest

`manifest.json` holds the sha256 of every file in this bundle (generated by `tools/hash_bundle.py`;
re-run it after any change). All paths are relative to this directory. `${HANDOFF}` is the unpacked
bundle and `${REPO}` the yapnr checkout; `localize.py` fills both in.

## Commands

```sh
# 0. unpack (gunzip/xz-decompress, fill in ${HANDOFF}/${REPO})
python3 examples/radar60/handoff-1v0buck/localize.py /path/to/handoff

# 1. independent DRC of a routed seed (zones refilled; the boards ship without fills)
cd /path/to/handoff/results/s1
kicad-cli pcb drc --refill-zones --severity-all --format json -o drc.json candidate.kicad_pcb
#    expected: drc/drc-fresh-local.json; the flow's own check is out/s1/files/measure.json

# 2. netlists and the comparison with the atopile board (KiCad's Python for netlist_json.py)
kicad-cli pcb export ipcd356 -o routed-s1.d356 candidate.kicad_pcb
<kicad python> ../../atopile/tools/netlist_json.py candidate.kicad_pcb routed-s1.netlist.json
python3 ../../atopile/tools/netlist_diff.py ../../atopile/netlist/rev-a.netlist.json routed-s1.netlist.json
python3 ../../atopile/tools/pin_tables.py ../../atopile

# 3. placement.json from a board
<kicad python> ../../tools/placement_from_board.py candidate.kicad_pcb placement.json

# 4. the flow from the seed (the steps the campaign ran: place, select, finish, route, check)
python3 ${REPO}/examples/radar60/board/integrate.py place  --work /path/to/handoff/seed --out <out> --engine ${REPO} --python <numeric python> --kicad-python <kicad python> --kicad-cli <kicad-cli> --library /path/to/handoff/seed/power-blocks-library.json --seed 1
#    then: select, finish, route, check with the same flags (see results/s1/logs/0*-*.log for the exact arguments)

# 5. the GCP campaign (needs the owner's cloud config)
python3 ${REPO}/tools/exp/pnr_explore_plan.py /path/to/handoff/explore_jobs_w4b.toml --repo ${REPO} --out <dir>
yapnr exp plan <dir>/campaign.toml --backend gcp-batch && yapnr exp submit <plan> --yes && yapnr exp fetch <plan> --full

# 6. EM: docs/simulations.md
```
