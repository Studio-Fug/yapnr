# RF fab-model test coupons: generated boards

The coupon boards of the [design](../../docs/design/rf-fab-coupons.md), generated by
`python -m yapnr.rf.coupons generate` and checked with KiCad's DRC (headless `kicad-cli`). The
user guide is [docs/rf-fab-coupons.md](../../docs/rf-fab-coupons.md). Do not edit these files:
change the generator and regenerate them.

| Directory                           | Board | Stackup                       | Panel (mm)    |
| ----------------------------------- | ----- | ----------------------------- | ------------- |
| [JLC04161H-7628](JLC04161H-7628/)   | A     | 4 layers, L1 GCPW, microstrip | 176 × 182     |
| [JLC06161H-2116C](JLC06161H-2116C/) | B     | 6 layers, L3 stripline        | 224 × 120     |
| [order0](order0/README.md)          | O     | OSH Park 4 layers, Order 0    | three uploads |

Each directory holds:

- `board-<A|B>.kicad_pro`, `.kicad_pcb`, `.kicad_dru`: the KiCad 10 project, zones unfilled
  (KiCad fills them on DRC, plot and open), with the stackup in the board setup;
- `catalog.json` (`yapnr-coupon-catalog/1`): every stick, its structure, dimensions, reference
  planes and model elements;
- `drc-summary.json`: the DRC result (no violations, no unconnected items);
- `expected/*.s2p`: the predicted S-parameters of every modelled stick, reference plane to
  reference plane, renormalized to 50 Ω, 0.1-18 GHz;
- `fab/board-<A|B>-fab.zip`: Gerbers, drill files and the fab notes; `fab/fab-notes.md`: the
  order options and the unverified items to check before ordering.

[measurements/](measurements/README.md) describes how a measured session is laid out.
