# Order 0: the OSH Park 4-layer boards (board O)

The three OSH Park uploads of Order 0 ([docs/rf/order0/](../../../docs/rf/order0/README.md)),
generated by `python -m yapnr.rf.coupons generate --stackup OSHPARK-4L-FR408HR --upload <M|W|D>`
and checked with KiCad's DRC under OSH Park's 4-layer rules and with
`yapnr fab check --vendor oshpark --profile oshpark-4l --stackup oshpark-4l-fr408hr`. Do not edit
these files: change the generator and regenerate them.

| Directory     | Upload | Contents                                                      |
| ------------- | ------ | ------------------------------------------------------------- |
| [O0-M](O0-M/) | O0-M   | region M coupons, R1, A16 C-pads, A04R, the tag (QR)          |
| [O0-W](O0-W/) | O0-W   | region W calibration set, R1t, the D2 window (placeholder)    |
| [O0-D](O0-D/) | O0-D   | the D1 window (placeholder), an R1 copy, a thru, a 30 mm line |

Each directory holds the KiCad 10 project (`.kicad_pro`, `.kicad_pcb` with unfilled zones,
`.kicad_dru`: the intentional mask openings and the mouse-bite holes on the break-off edges),
`catalog.json` (every stick, its geometry, model elements, placement in the panel, the panel's
size in square inches) and `drc-summary.json`. The fab bundle (Gerbers, drill, order card) is built
later with `yapnr fab build`; agents never upload or order.

The demo windows are placeholders: the optimizer's copper of D1 and D2 goes into them when each
passes its validation, with its feeds, keep-away and launches already in place.
