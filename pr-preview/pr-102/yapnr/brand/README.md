# yapnr brand assets

The owner-provided October 2026 brand kit supplies the original tree with the
Space Grotesk wordmark, compact marks, colors and interaction specification.
The primary SVG lockups retain the full original tree. Compact marks are for
small application headers and favicons.

Space Grotesk, IBM Plex Sans and IBM Plex Mono are bundled under the SIL Open
Font License; their original license files accompany the fonts. WOFF2 conversion
preserves the font names, metadata and glyphs. No font network service is used.

The engineering workbench and existing viewer share these assets and tokens.
Board copper colors keep their layer meanings. Overlays alone use tinted glass;
working content is opaque, with reduced-transparency and reduced-motion support.
The implementation uses actual workspace artifacts and runtime evidence, not the
kit's illustrative geometry, conversations or timing data.
